# Part 1: On-chain Database & SQL Foundations

## 📌 Overview

This section covers the core fundamentals of DuneSQL (Trino) and on-chain raw ledger data. It focuses on building robust data pipelines, handling exceptions, and mastering essential SQL syntax to transition from a beginner to an on-chain data analyst.

## 🎯 Core Competencies

- Understand the structural differences between traditional RDBMS and On-chain Ledgers.
- Master DuneSQL syntax and time-partitioning optimization for query efficiency.
- Decode EVM raw transactions and control BigInt overflows securely.
- Reconstruct accurate fund flows using CTEs and Window Functions.
